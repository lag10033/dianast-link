# link.dianast.by

Мобильная страница-визитка завода колотого кирпича DIANAST: расчёт забора за минуту,
выбор цвета кирпича, контакты в один тап.

Одна самодостаточная страница (`index.html`), вся вёрстка и скрипты внутри файла.
Картинки — в `img/`. Хостинг: GitHub Pages, домен подключён через `CNAME`.
